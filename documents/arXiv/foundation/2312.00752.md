# Mamba: 選択的状態空間による線形時間系列モデリング

Albert Gu, Tri Dao

## 概要

現在の深層学習における主要な応用を支える Foundation Model のほとんどは、Transformer アーキテクチャと、その中核である attention モジュールに基づいている。長系列に対する Transformer の計算効率の悪さを解決するため、linear attention、gated convolution、recurrent model、structured state space model (SSM) など、二次時間未満で動作する多くのアーキテクチャが提案されてきた。しかし、言語のような重要なモダリティでは、これらは attention と同等の性能には達していなかった。

本研究では、その主要な弱点が content-based reasoning を行う能力の不足にあることを特定し、いくつかの改善を導入する。第一に、SSM のパラメータを入力の関数とするだけで、離散モダリティに対する弱点を改善できる。これにより、現在の token に応じて系列長方向に情報を選択的に伝播したり忘却したりできる。第二に、この変更によって効率的な convolution を利用できなくなるにもかかわらず、recurrent mode で動作する hardware-aware な並列アルゴリズムを設計する。さらに、この selective SSM を attention や MLP block すら持たない単純な end-to-end neural network architecture に統合し、**Mamba** と呼ぶ。

Mamba は高速な推論（Transformer の約 $5\times$ の throughput）と系列長に対する線形スケーリングを実現し、実データでは系列長 100 万まで性能が向上する。汎用的な sequence model backbone として、Mamba は言語・音声・genomics など複数のモダリティで state-of-the-art の性能を達成する。language modeling では、Mamba-3B は同規模の Transformer を上回り、pretraining と downstream evaluation の双方で約 2 倍規模の Transformer と同等の性能を示す。

# 1. はじめに

Foundation Model (FM)、すなわち大規模データで事前学習され、その後 downstream task に適応される大規模モデルは、現代の機械学習における有効なパラダイムとなっている。FM の backbone はしばしば sequence model であり、言語、画像、音声、audio、時系列、genomics など、さまざまな領域の任意の入力系列を処理する (Brown et al. 2020; Dosovitskiy et al. 2020; Ismail Fawaz et al. 2019; Oord et al. 2016; Poli et al. 2023; Sutskever, Vinyals, and Quoc V Le 2014)。

この考え方自体は特定のアーキテクチャに依存しないが、現代の FM は主として Transformer (Vaswani et al. 2017) とその中核である attention layer (Bahdanau, Cho, and Bengio 2015) に基づいている。self-attention が有効なのは、context window 内で情報を密に routing でき、複雑なデータをモデリングできるためだと考えられる。一方で、この性質には根本的な欠点がある。有限の window の外側を直接モデリングできず、計算量が window length の二乗で増加する。これを克服するため効率的な attention variant が多数提案されてきた (Tay, Dehghani, Bahri, et al. 2022) が、多くの場合、attention を有効にしている性質そのものを犠牲にしている。現時点まで、こうした variant のうち、複数領域で大規模に attention と同等の経験的性能を示したものはなかった。

近年、structured state space sequence model (SSM) (Gu, Goel, and Ré 2022; Gu, Johnson, Goel, et al. 2021) が有望な系列モデリング手法として登場した。SSM は、古典的 state space model (Kalman 1960) に着想を得つつ、RNN と CNN を組み合わせたものとして解釈できる。recurrence と convolution のどちらとしても効率的に計算でき、系列長に対して線形または準線形にスケールする。また、一部のデータモダリティでは長距離依存を扱うための原理的な機構を持ち (Gu, Dao, et al. 2020)、Long Range Arena などの benchmark で優れた性能を示してきた (Tay, Dehghani, Abnar, et al. 2021)。S4 の多数の派生手法は audio や vision のような連続信号データで成功しているが、text のような離散かつ情報密度の高いデータでは比較的弱い。

本研究では、Transformer に匹敵するモデリング能力を持ちながら系列長に対して線形にスケールする、新しい **selective state space model** を提案する。

### Selection Mechanism

従来モデルの重要な制約は、入力に依存してデータを効率的に選択する、すなわち特定の入力に注目したり無視したりする能力である。Selective Copying や Induction Heads といった重要な synthetic task から着想を得て、SSM のパラメータを入力の関数とする単純な selection mechanism を設計する。これにより、無関係な情報を除外し、関連する情報を必要なだけ長く保持できる。

### Hardware-aware Algorithm

この単純な変更は計算上の難しさを生む。従来の SSM は効率的に計算するために time-invariant かつ input-invariant である必要があった。本研究では convolution の代わりに recurrent scan を使いつつ、GPU の memory hierarchy 間での IO を避けるため expanded state を低速メモリ上に materialize しない hardware-aware algorithm を設計する。その結果、理論上は系列長に線形にスケールし、実際の A100 GPU 上でも従来手法より最大約 $3\times$ 高速になる。

### Architecture

従来の SSM architecture (Dao, Fu, Saab, et al. 2023) と Transformer の MLP block を単一 block に統合し、単純で均質な architecture とする。これが selective state space を組み込んだ **Mamba** である。

Selective SSM と Mamba は完全な recurrent model であり、general-purpose FM backbone に適する次の性質を持つ。

- **高品質**: selectivity により、language や genomics のような高密度モダリティで高性能を得る。
- **高速な学習と推論**: 学習時の計算量とメモリは系列長に線形であり、autoregressive inference では過去要素の cache を必要としないため、1 step あたり定数時間で処理できる。
- **long context**: 品質と効率の組み合わせにより、実データで系列長 1M まで性能向上を確認する。

Mamba の汎用 sequence FM backbone としての能力を、次の領域で検証する。

- **Synthetic task**: copying と induction head を容易に解き、学習時よりはるかに長い $>1$M token にまで外挿する。
- **Audio と genomics**: audio waveform と DNA sequence modeling で SaShiMi、Hyena、Transformer などを上回る。難しい speech generation dataset では FID を半分以下に低減し、context length を 100 万程度まで伸ばすほど性能が向上する。
- **Language Modeling**: Transformer 品質に到達した初の linear-time sequence model である。1B parameter までの scaling law で、LLaMA 系の強力な Transformer recipe を含む各種 baseline を上回る。同規模 Transformer の約 $5\times$ の generation throughput を持ち、Mamba-3B は約 2 倍規模の Transformer と同等の品質を示す。

# 2. State Space Models

Structured state space sequence model (S4) は、RNN、CNN、古典的 state space model と広く関係する sequence model である。1 次元関数または系列 $x(t)\in\mathbb{R}$ を、潜在状態 $h(t)\in\mathbb{R}^{N}$ を介して $y(t)\in\mathbb{R}$ に写像する連続系として、

$$
h'(t)=\mathbf{A}h(t)+\mathbf{B}x(t) \tag{1a}
$$

$$
y(t)=\mathbf{C}h(t) \tag{1b}
$$

を考える。S4 は $(\Delta,\mathbf{A},\mathbf{B},\mathbf{C})$ の 4 つのパラメータで定義され、まず連続系を離散化し、その後系列変換を計算する。

離散時間では、

$$
h_t=\overline{\mathbf{A}}h_{t-1}+\overline{\mathbf{B}}x_t \tag{2a}
$$

$$
y_t=\mathbf{C}h_t \tag{2b}
$$

と書ける。一方、LTI の場合には recurrence を展開して convolution kernel

$$
\overline{\mathbf{K}}
=
(\mathbf{C}\overline{\mathbf{B}},
\mathbf{C}\overline{\mathbf{A}}\overline{\mathbf{B}},
\ldots,
\mathbf{C}\overline{\mathbf{A}}^k\overline{\mathbf{B}},
\ldots) \tag{3a}
$$

を構成し、

$$
y=x*\overline{\mathbf{K}} \tag{3b}
$$

として計算できる。

## 離散化

最初の段階では、「continuous parameter」$(\Delta,\mathbf{A},\mathbf{B})$ を固定の離散化則 $f_A,f_B$ により「discrete parameter」$(\overline{\mathbf{A}},\overline{\mathbf{B}})$ へ変換する。

$$
\overline{\mathbf{A}}=f_A(\Delta,\mathbf{A}),
\qquad
\overline{\mathbf{B}}=f_B(\Delta,\mathbf{A},\mathbf{B}).
$$

例えば zero-order hold (ZOH) では、

$$
\overline{\mathbf{A}}=\exp(\Delta\mathbf{A}),
\qquad
\overline{\mathbf{B}}
=(\Delta\mathbf{A})^{-1}
(\exp(\Delta\mathbf{A})-\mathbf{I})\cdot\Delta\mathbf{B}. \tag{4}
$$

離散化は continuous-time system と深く関係し、resolution invariance や適切な normalization などの性質を与える。また RNN の gating mechanism とも関係し、この点は Section 3.5 で再び扱う。forward pass の計算グラフという観点では、離散化は単に SSM 計算の最初の処理とみなすこともできる。別の SSM variant では離散化を飛ばし、$(\overline{\mathbf{A}},\overline{\mathbf{B}})$ を直接 parameterize してもよい。

## 計算

$(\Delta,\mathbf{A},\mathbf{B},\mathbf{C})$ を $(\overline{\mathbf{A}},\overline{\mathbf{B}},\mathbf{C})$ へ変換した後、SSM は式 (2) の linear recurrence または式 (3) の global convolution として計算できる。一般に、系列全体が利用できる学習時には並列化しやすい convolution mode を用い、入力が 1 timestep ずつ与えられる autoregressive inference では recurrent mode に切り替える。

## Linear Time Invariance (LTI)

式 (1)〜(3) の重要な性質は、モデルの dynamics が時間に対して一定であることである。すなわち $(\Delta,\mathbf{A},\mathbf{B},\mathbf{C})$、したがって $(\overline{\mathbf{A}},\overline{\mathbf{B}})$ も全 timestep で固定される。この性質を linear time invariance (LTI) と呼ぶ。LTI SSM は、概念的には linear recurrence または convolution と等価である。

これまでの structured SSM は、効率上の制約から基本的にすべて LTI であった。本研究の中心的な洞察は、LTI model には特定の種類のデータをモデリングする際に根本的な限界があり、その LTI 制約を外しつつ効率ボトルネックを克服する必要があるという点にある。

## 構造と次元

Structured SSM では効率的に計算するため $\mathbf{A}$ に構造を課す。最も一般的なのは diagonal structure であり、本研究でもこれを用いる。この場合、$\mathbf{A}\in\mathbb{R}^{N\times N}$、$\mathbf{B}\in\mathbb{R}^{N\times1}$、$\mathbf{C}\in\mathbb{R}^{1\times N}$ はそれぞれ $N$ 個の数で表現できる。

batch size $B$、sequence length $L$、channel dimension $D$ の入力 $x$ に対して SSM は各 channel に独立に適用される。このとき 1 入力あたりの hidden state 全体は $DN$ 次元となり、系列全体の計算には $O(BLDN)$ の時間とメモリが必要になる。これが Section 3.3 で扱う主要な効率問題である。

## 一般的な State Space Model との区別

state space model という語は本来、latent state を持つ任意の recurrent process を広く指し、MDP、dynamic causal modeling、Kalman filter、HMM、linear dynamical system、RNN などにも使われる。本論文では「SSM」を structured SSM / S4 系列のモデルに限定して用いる。

## SSM Architecture

SSM は独立した sequence transformation であり、end-to-end neural architecture 内の layer として組み込める。代表例は次の通りである。

- **Linear attention**: self-attention の近似であり、degenerate linear SSM とみなせる recurrence を持つ。
- **H3**: linear attention の recurrence を S4 に一般化し、SSM を 2 つの gated connection で挟む。main SSM の前に local convolution も置く。
- **Hyena**: H3 と同様の architecture だが、S4 を MLP-parameterized global convolution に置換する。
- **RetNet**: gate を追加し、より単純な SSM を利用することで、convolution の代わりに multi-head attention に似た並列計算経路を持つ。
- **RWKV**: attention-free Transformer に基づく RNN で、主要な WKV mechanism は LTI recurrence を含み、2 つの SSM の比として解釈できる。

# 3. Selective State Space Models

本節では、まず synthetic task から selection mechanism の動機を説明し、その後 SSM への導入方法、efficient selective scan、Mamba block、selection の性質を説明する。

## 3.1 Selection を圧縮として捉える

系列モデリングの根本問題の一つは、context をより小さな state に圧縮することである。この観点から見ると、一般的な sequence model の trade-off を統一的に理解できる。

attention は context をほぼ圧縮しないため強力だが非効率である。autoregressive inference では context 全体、すなわち KV cache を明示的に保存する必要があり、推論が系列長に比例し、学習が系列長の二乗に比例する。一方、recurrent model は有限 state のみを持つため、推論が定数時間、学習が線形時間で効率的である。ただし、その有効性は有限 state に context をどれだけ適切に圧縮できるかに依存する。

この原理を理解するため、2 つの synthetic task を考える。

- **Selective Copying**: 標準 Copying task で覚えるべき token の位置をランダム化する。関連 token を覚え、無関係な token を除外する content-aware reasoning が必要となる。
- **Induction Heads**: LLM の in-context learning の重要な機構と考えられている associative recall task である。適切な context で、過去に対応した token を取り出す必要がある。

LTI model では recurrent dynamics $(\overline{\mathbf{A}},\overline{\mathbf{B}})$ が一定であるため、context から情報を入力依存に選択できない。convolution の観点でも、標準 Copying は固定 kernel で解けるが、Selective Copying では入力と出力の間隔が変化するため static convolution kernel では対応できない。

したがって、sequence model の効率と有効性の trade-off は、state をどれだけうまく圧縮できるかで特徴づけられる。効率的なモデルは小さな state を持つ必要があり、有効なモデルの state には context から必要な情報がすべて含まれなければならない。本研究では、この両立のための基本原理を **selectivity**、すなわち context に応じて入力を state に取り込むか除外するかを制御する能力とする。

## 3.2 Selection による SSM の改善

系列方向の相互作用を決めるパラメータを入力依存にすることで selection mechanism を導入できる。標準 S4 と selective SSM (S6) の主要な違いは、$\Delta,\mathbf{B},\mathbf{C}$ を入力の関数とする点である。これにより各パラメータに sequence length dimension $L$ が入り、モデルは time-invariant から time-varying へ変化する。その代償として convolution との等価性は失われる。

本研究では、

$$
s_B(x)=\mathrm{Linear}_N(x),
$$

$$
s_C(x)=\mathrm{Linear}_N(x),
$$

$$
s_\Delta(x)=\mathrm{Broadcast}_D(\mathrm{Linear}_1(x)),
$$

$$
\tau_\Delta=\mathrm{softplus}
$$

を用いる。$\mathrm{Linear}_d$ は $d$ 次元への learnable projection である。$s_\Delta$ と $\tau_\Delta$ の形は RNN gating との関係から導かれる。

### Algorithm 1: SSM (S4)

```text
Input : x : (B, L, D)
Output: y : (B, L, D)

A : (D, N) <- Parameter
B : (D, N) <- Parameter
C : (D, N) <- Parameter
Delta : (D) <- tau_Delta(Parameter)
A_bar, B_bar : (D, N) <- discretize(Delta, A, B)
y <- SSM(A_bar, B_bar, C)(x)
     # time-invariant: recurrence または convolution
return y
```

### Algorithm 2: SSM + Selection (S6)

```text
Input : x : (B, L, D)
Output: y : (B, L, D)

A : (D, N) <- Parameter
B : (B, L, N) <- s_B(x)
C : (B, L, N) <- s_C(x)
Delta : (B, L, D) <- tau_Delta(Parameter + s_Delta(x))
A_bar, B_bar : (B, L, D, N) <- discretize(Delta, A, B)
y <- SSM(A_bar, B_bar, C)(x)
     # time-varying: recurrence (scan) のみ
return y
```

## 3.3 Selective SSM の効率的実装

convolution や attention は現代 GPU 上で高速に計算できる primitive であり、それが普及の大きな理由である。selective SSM も同様に hardware efficient である必要がある。

### 3.3.1 従来モデルの動機

recurrent model は表現力と速度の trade-off を持つ。hidden state が大きいほど表現力は高くなるが、通常は遅くなる。本研究では、速度・メモリのコストを大きく増やさず hidden state dimension を最大化したい。

recurrent mode は convolution mode より柔軟である。convolution は recurrence の展開から導出されるからである。しかし、直接 recurrence を計算すると latent state $h$ の shape は $(B,L,D,N)$ となり、入力・出力 $(B,L,D)$ より $N$ 倍大きい。従来の LTI SSM は recurrent/convolutional duality を利用し、state dimension を通常の RNN より約 $10$〜$100\times$ 大きくしながら、その expanded state を明示的に保存しないことで効率を維持した。

### 3.3.2 Selective Scan: Hardware-aware State Expansion

selection mechanism により convolution が使えなくなるため、SSM の計算問題を再検討する。本研究では **kernel fusion、parallel scan、recomputation** の 3 つを利用する。

naive recurrent computation の FLOPs は $O(BLDN)$、convolutional computation は $O(BLD\log L)$ であり、recurrent computation の定数係数は小さい。したがって、系列が長く $N$ が過度に大きくなければ、recurrent mode の FLOPs 自体はむしろ少なくなり得る。問題は recurrence の逐次性と、大きな state を保存する memory usage である。

本研究の主要アイデアは、expanded state $h$ を GPU memory hierarchy の高速な階層にのみ materialize することである。matrix multiplication を除く多くの演算は memory bandwidth bound であり、scan もこれに該当する。kernel fusion により memory IO を削減する。

具体的には、$(B,L,D,N)$ の $\overline{\mathbf{A}},\overline{\mathbf{B}}$ を GPU HBM に展開するのではなく、SSM parameter $(\Delta,\mathbf{A},\mathbf{B},\mathbf{C})$ を HBM から SRAM に読み込み、SRAM 内で discretization と recurrence を行い、最終出力 $(B,L,D)$ のみを HBM に書き戻す。

recurrence の逐次性については、linear ではない場合でも work-efficient parallel scan で並列化できる。backpropagation に必要な intermediate state も HBM には保存せず、backward pass 時に recompute する。これにより、fused selective scan layer の memory requirement は FlashAttention を用いた optimized Transformer と同程度になる。

## 3.4 単純化した SSM Architecture

selective SSM 自体は単独の sequence transformation であり、各種 neural network に組み込める。従来の代表的な SSM architecture である H3 は、linear attention に着想を得た block と MLP block を交互に配置する。本研究ではこれらを 1 つに統合し、同一 block を均質に stack する。これは Gated Attention Unit (GAU) の発想にも近い。

Mamba block は model dimension $D$ を expansion factor $E$ により内部で拡張する。1 block の parameter の大部分は linear projection にあり、入力 projection に $2ED^2$、出力 projection に $ED^2$、合計で約 $3ED^2$ である。$\Delta,\mathbf{B},\mathbf{C},\mathbf{A}$ に対応する SSM parameter は相対的に小さい。

この block を normalization と residual connection を挟みながら繰り返して Mamba architecture を構成する。実験では常に $E=2$ とし、Transformer の MHA + MLP 2 block が持つおよそ $12D^2$ parameter に合わせるため Mamba block を 2 stack 用いる。activation には SiLU / Swish を用いる。

## 3.5 Selection Mechanism の性質

selection mechanism は系列に沿った情報伝播を入力依存に制御する。その動作を理解するには、$\Delta$、$\mathbf{A}$、$\mathbf{B}$、$\mathbf{C}$ の役割を個別に考えるとよい。

### 3.5.1 RNN Gating との関係

selective SSM は、古典的 RNN gating を一般化したものとして解釈できる。特に state dimension $N=1$、$\mathbf{A}=-1$、$\mathbf{B}=1$ とし、$\Delta$ を入力依存にすると、ZOH discretization から

$$
g_t=\sigma(\mathrm{Linear}(x_t)),
$$

$$
h_t=(1-g_t)h_{t-1}+g_t x_t \tag{5}
$$

という gated recurrence が得られる。したがって、RNN の gate は selective SSM の特殊例である。

### 3.5.2 Selection の解釈

**Variable Spacing.** $\Delta$ は continuous system を離散化するときの step size として解釈できる。入力に応じて $\Delta$ を変えることで、モデルは token 間の「実効的な時間間隔」を伸縮させ、Selective Copying のような可変間隔を扱える。

**Filtering Context.** $\Delta$ が小さければ state の変化は小さく、入力をほぼ無視できる。大きければ state を大きく更新し、新しい入力を強く取り込める。このため、モデルは無関係な token を除外し、重要な token を選択的に保持できる。

**Boundary Resetting.** 大きな $\Delta$ は過去の state を強く減衰させるため、document boundary のような位置で state を事実上 reset する機構としても働ける。

**$\Delta$ の解釈.** $\Delta$ は selective SSM の主要な gating parameter であり、入力を「どれだけ通すか」を制御する。

**$\mathbf{A}$ の解釈.** $\mathbf{A}$ は state の decay / dynamics を決める。$\Delta$ と組み合わされることで、入力依存の忘却速度を生む。

**$\mathbf{B},\mathbf{C}$ の解釈.** $\mathbf{B}$ は入力を latent state のどの成分へ書き込むか、$\mathbf{C}$ は latent state のどの成分を読み出すかを入力依存に選択する。したがって $N>1$ の expanded state を有効に利用するために重要である。

## 3.6 追加のモデル詳細

### Real vs. Complex

従来の S4 は complex-valued state をしばしば利用するが、本研究では原則として real-valued SSM を用いる。hardware efficiency の点で real parameterization は扱いやすく、language modeling では性能上の不利益もほとんどない。long-form audio waveform の実験のみ complex-valued parameterization を利用する。

### Initialization

complex case の default initialization は S4D-Lin、real case は S4D-Real とする。これは HIPPO theory に基づき、それぞれ

$$
A_n=-\frac12+ni,
\qquad
A_n=-(n+1)
$$

と定義される。ただし large-data / real-valued regime では、多くの initialization が十分に機能すると予想される。

### $\Delta$ の parameterization

$s_\Delta(x)=\mathrm{Broadcast}_D(\mathrm{Linear}_1(x))$ は、projection dimension を $1$ からより大きな $R$ へ一般化できる。$R$ を $D$ の小さな割合にすれば parameter 増加はわずかである。Broadcast は特定の 0/1 pattern で初期化した別の Linear projection とみなせるため、trainable にすると

$$
s_\Delta(x)=\mathrm{Linear}_D(\mathrm{Linear}_R(x))
$$

という low-rank projection として解釈できる。

$\Delta$ の bias parameter は、従来 SSM に従い

$$
\tau_\Delta^{-1}(\mathrm{Uniform}([0.001,0.1]))
$$

で初期化する。

本論文では、S4 に **selection** を追加し **scan** で計算するモデルであることから、selective SSM を簡略に **S6** と呼ぶことがある。

# 4. 実験評価

Section 4.1 では Selective Copying と Induction Heads の synthetic task を評価する。その後、language、DNA、audio の 3 領域について、autoregressive pretraining と downstream task の両方を評価する。さらに speed / memory benchmark と model ablation を行う。

## 4.1 Synthetic Tasks

### 4.1.2 Induction Heads

Induction head は mechanistic interpretability の観点から研究される simple task で、LLM の in-context learning 能力を強く予測するとされる。例えば系列中で一度 “Harry Potter” という bigram を見たなら、次に “Harry” が現れた際に過去から “Potter” を recall する必要がある。

2-layer model を sequence length $256$、vocabulary size $16$ で学習し、test 時には $2^6=64$ から $2^{20}=1,048,576$ まで系列長を変化させる。attention model は 8-head MHA と複数の positional encoding を用い、SSM variant と比較する。Mamba の model dimension は $D=64$、その他は $D=128$ とする。

Mamba、より正確にはその selective SSM layer は、関連 token を選択的に保持し、間にある無関係な token を無視できるため task を完全に解く。学習時の約 $4000\times$ にあたる 100 万 token の系列まで完全に一般化する。他手法はいずれも $2\times$ を超える外挿に失敗する。

## 4.3 DNA Modeling

大規模 language model の成功を受け、genomics でも foundation model paradigm が検討されている。DNA は有限 vocabulary の離散 token 系列であり、長距離依存を必要とする点で language と類似する。本研究では HyenaDNA の設定に従い、HG38 human genome dataset（training split 約 45 億 base pair）で causal next-token prediction を行う。

### 4.3.1 Model Size の Scaling

context length を $2^{10}=1024$ に固定し、約 200K から約 40M parameter まで model size を増やす。Mamba は HyenaDNA および Transformer++ より良好な scaling を示す。

### 4.3.2 Context Length の Scaling

model size、tokens/batch、総 training token 数を固定したまま、sequence length を $2^{10}$ から $2^{20}\approx 1$M まで増やす。Mamba は context length が長くなるほど pretraining perplexity が改善する。一方 HyenaDNA は長くすると悪化する。

LTI model は情報を選択的に捨てられず、非常に長い convolution kernel では長系列全体の noisy information を集約してしまう。selective SSM では必要な情報を選択できるため、長い context を有効利用できる。

# 5. 議論

## Related Work

selection mechanism と類似概念との関係、および SSM / related model の詳細は Appendix A, B で議論する。

## No Free Lunch: Continuous-Discrete Spectrum

Structured SSM は元来 continuous system の discretization として定義され、audio や video のような continuous-time perceptual signal に対して強い inductive bias を持つ。selection mechanism は text や DNA のような discrete modality に対する弱点を克服する一方、LTI SSM が得意なデータでは逆に performance を損なう可能性がある。audio waveform の ablation はこの trade-off を実際に示す。

## Downstream Affordances

Transformer-based FM、特に LLM には fine-tuning、adaptation、prompting、in-context learning、instruction tuning、RLHF、quantization など豊富な利用形態がある。SSM のような Transformer 代替 architecture が同様の性質を持つかは重要な今後の研究課題である。

## Scaling

本論文の empirical evaluation は比較的小規模な model に限定される。Llama や RWKV、RetNet などは 7B parameter 以上で評価されており、より大規模な領域でも Mamba が有利かは今後検証が必要である。また、大規模 SSM の training には、本論文で扱わない追加の engineering challenge が生じる可能性がある。

# 6. 結論

Structured state space model に selection mechanism を導入し、系列長に対して線形にスケールしながら context-dependent reasoning を可能にした。これを単純な attention-free architecture に組み込んだ Mamba は、幅広い領域で state-of-the-art の性能を達成し、強力な Transformer と同等またはそれ以上の結果を示す。

特に genomics、audio、video のように長い context を必要とする emerging modality に対し、selective SSM は有望である。結果は、Mamba が汎用 sequence model backbone の強力な候補であることを示している。

# Appendix A. Selection Mechanism に関する議論

本研究の selection mechanism は gating、hypernetwork、data-dependence、fast weights などと関連するが、それらと同一ではない。

## Gating

gating は元来 LSTM や GRU のような RNN の gate、すなわち入力を hidden state に取り込むかどうかを制御する機構を指した。この意味の gate は時間方向の signal propagation を直接変化させ、sequence length 方向に入力同士を相互作用させる。

一方、現在は activation を伴う elementwise multiplication まで広く「gating」と呼ばれる。sequence direction に相互作用しない単純な multiplicative branch も gated architecture と呼ばれるため、古典的 RNN gating と現代的な用語法は意味的にかなり異なる。

## Hypernetwork と Data-dependence

Hypernetwork は、ある network の parameter を別の小さな network が生成する考え方である。data-dependence も同様に、model parameter の一部が入力 data に依存する一般的な概念を指す。

例えば diagonal linear layer $y=\mathbf{D}x$ に対し、$\mathbf{D}=\sigma(\mathbf{W}x)$ とすれば、

$$
y=\sigma(\mathbf{W}x)\circ x
$$

となる。これは gating、hypernetwork、data-dependent のいずれにも形式的には該当するが、実際には単純な GLU activation にすぎない。このため、これらの広い概念だけでは selection mechanism の本質を十分に表現できない。

## Selection

selection は、入力を選択または無視し、sequence length 方向の情報伝播・相互作用を制御する mechanistic action を指す。traditional RNN gating はその特殊例であり、input-dependent convolution や attention も広い意味では類似の作用を持ち得る。本論文では用語の混同を避けるため、単なる multiplicative gating ではなく **selection** という語を用いる。

# Appendix B. Related Work

## B.1 S4 Variant と派生手法

- **S4** は最初の structured SSM を導入し、diagonal および diagonal-plus-low-rank (DPLR) structure を扱った。HIPPO による continuous-time online memorization との関係から、DPLR SSM を convolution として効率的に計算した。
- **DSS** は HIPPO initialization を近似することで diagonal structured SSM が経験的に有効であることを示し、S4D が理論面を発展させた。
- **S5** は diagonal SSM approximation を独立に発見し、S4 系で初めて parallel scan を recurrent computation に用いた。ただし state dimension を縮小する必要があり、SISO から MIMO formulation に変更した。S6 は scan を共有する一方、SISO の大きな effective state を維持し、hardware-aware algorithm と selection mechanism を追加する。
- **Mega** は S4 を real-valued に単純化し、exponential moving average (EMA) として解釈した。また discretization と EMA damping の関係を示した。
- **Liquid S4** は input-dependent state transition を導入する点で selection に近いが、依然 convolutional かつ LTI に近い限定的な形式である。
- **SGConv、Hyena、LongConv、MultiresConv、Toeplitz Neural Network** は S4 の convolution representation に着目し、global / long convolution kernel の parameterization を工夫する。しかし直接的な高速 autoregressive inference は難しい。

これらの structured SSM は、原則として non-selective かつ LTI である。

## B.2 SSM Architecture

- **GSS** は SSM を組み込んだ初期の gated architecture で、GAU に着想を得ている。GSS は SSM state size を減らすため model dimension を縮小するのに対し、Mamba は state size を増やすため内部 dimension を拡張する。
- **Mega** は real-valued EMA SSM と efficient attention approximation を組み合わせる。
- **H3** は S4 と linear attention を組み合わせ、linear attention recurrence をより一般的な recurrence に拡張した。
- **Selective S4** は S4 を black box として binary mask を生成し入力に掛ける。名称は近いが、sequence spacing 自体を変えられないため、本論文の selection mechanism より architecture gating に近い。
- **RetNet** は H3 / linear attention に近く、state dimension $N=1$ の特殊な SSM を用いる。large head dimension により input-dependent state expansion を実現し、特殊な EMA structure によって MHA に似た並列計算を可能にする。
- **RWKV** は Attention-Free Transformer に基づく RNN であり、WKV recurrence は LTI SSM として解釈できる。

GAU は Transformer の MHA と MLP を単一 block にまとめる発想を持ち、Mamba architecture の設計にも影響を与えている。

## B.3 RNN との関係

RNN と SSM は latent state 上の recurrence を共有する。Strongly Typed RNN、QRNN、SRU などは、時間方向の非線形性を持たない gated recurrence を利用し、selection mechanism の観点から selective SSM の特殊例と解釈できる。ただし、これらには主に次の差がある。

- state expansion を持たず $N=1$ である。
- selective $\mathbf{B},\mathbf{C}$ を持たない。
- heuristic な gating を用いるのに対し、Mamba では selection + discretization から gate を導出し、SSM theory に基づく parameterization / initialization を利用する。

古典的 RNN の sequential computation による efficiency problem は parallel scan で改善できる。一方、vanishing gradient への対処には、SSM theory に基づく recurrent dynamics の parameterization / discretization が重要になる。

orthogonal / unitary RNN は transition matrix $\mathbf{A}$ の eigenvalue を制御して vanishing gradient を防ぐが、依然 LTI であるため Selective Copying のような task に弱い。

## B.4 Linear Attention

Linear Attention (LA) は kernel attention と recurrent autoregressive model の等価性を広めた重要な framework である。Random Feature Attention は Gaussian kernel の random Fourier feature により softmax attention を近似し、Performer は positive feature による exponential kernel approximation を用いる。TransNormer は LA の denominator の不安定性を LayerNorm で置き換え、cosFormer は cosine reweighting により locality を加え、Linear Randomized Attention は importance sampling の観点から softmax kernel approximation を一般化した。

## B.5 Long Context Model

多くの recent model が非常に長い context length を扱えると主張しているが、その多くは計算可能性を示すにとどまり、実 task で quality が context length とともに改善することを十分には検証していない。

- Recurrent Memory Transformer は synthetic memorization task で 1M length への generalization を示した。
- LongNet は理論上 1B length を主張するが、実 task での評価は 100K 未満である。
- Hyena / HyenaDNA は 1M context を利用するが、long context ほど training data / computation も増える設定があり、context length 自体の効果を分離しにくい。

本研究は、計算量を制御した上で、context length を長くするほど実データ performance が向上することを明示的に示す試みの一つである。

# Appendix C. Selective SSM の力学

Theorem 1 の証明を示す。$N=1$、$\mathbf{A}=-1$、$\mathbf{B}=1$、$s_\Delta=\mathrm{Linear}(x)$、$\tau_\Delta=\mathrm{softplus}$ とする。対応する continuous-time SSM は

$$
h'(t)=-h(t)+x(t)
$$

であり、leaky integrator とも呼ばれる。

離散化 step size は

$$
\Delta_t
=\tau_\Delta(\mathrm{Parameter}+s_\Delta(x_t))
=\mathrm{softplus}(\mathrm{Parameter}+\mathrm{Linear}(x_t))
=\mathrm{softplus}(\mathrm{Linear}(x_t)),
$$

となる。parameter は learnable bias とみなし Linear に吸収できる。

ZOH discretization を適用すると、

$$
\overline{A}_t
=\exp(\Delta A)
=\frac{1}{1+\exp(\mathrm{Linear}(x_t))}
=\sigma(-\mathrm{Linear}(x_t))
=1-\sigma(\mathrm{Linear}(x_t)),
$$

$$
\overline{B}_t
=(\Delta A)^{-1}(\exp(\Delta A)-I)\Delta B
=-(\exp(\Delta A)-I)
=1-\overline{A}_t
=\sigma(\mathrm{Linear}(x_t)).
$$

したがって離散 recurrence は

$$
g_t=\sigma(\mathrm{Linear}(x_t)),
$$

$$
h_t=(1-g_t)h_{t-1}+g_t x_t,
$$

となり、標準的 gated recurrence が得られる。

# Appendix D. Selective SSM の Hardware-aware Algorithm

input-dependent selectivity がない SSM は FFT primitive を用いた convolution として効率的に計算できる。selectivity を導入すると convolution との等価性は失われるため、parallel associative scan を利用する。scan の理論計算量は $O(BLDN)$ で系列長 $L$ に線形だが、Foundation Model を学習するには GPU 上でも実際に高速でなければならない。

## Speed

GPU では matrix multiplication を除く多くの operation が memory-bandwidth bound である。standard scan 実装では、$(B,L,D,N)$ の $\overline{\mathbf{A}},\overline{\mathbf{B}}$ を HBM に用意し、parallel scan の出力 $(B,L,D,N)$ を再び HBM に書き、その後 $\mathbf{C}$ と乗算して $(B,L,D)$ を得る。この方法では $O(BLDN)$ 規模の memory read/write が発生する。

そこで discretization、scan、$\mathbf{C}$ との乗算を 1 kernel に fuse する。

1. $\Delta,\mathbf{A},\mathbf{B},\mathbf{C}$ の $O(BLD+DN)$ bytes を HBM から SRAM に読む。
2. SRAM 内で discretize し、$(B,L,D,N)$ の $\overline{\mathbf{A}},\overline{\mathbf{B}}$ を生成する。
3. SRAM 内で parallel associative scan を実行し、intermediate state $(B,L,D,N)$ を得る。
4. $\mathbf{C}$ との multiply / sum により $(B,L,D)$ を生成し、それだけを HBM へ書く。

これにより IO を state dimension $N$ の factor だけ削減し、実際には standard implementation より約 $20$〜$40\times$ 高速になる。sequence が SRAM に収まらない場合には chunk に分割し、intermediate scan state を次 chunk へ引き継ぐ。

## Memory

forward pass では $(B,L,D,N)$ の intermediate state を保存しない。しかし backward pass には必要なので、backward 時に再計算する。入力と output gradient は HBM から SRAM に読み込み、state は SRAM 内で recompute する。state 全体を HBM に保存して再読込するより、recompute の方が memory IO を減らせるため、むしろ高速になる。

さらに selective SSM block 全体でも、activation output や short convolution output のような再計算が安価で memory を多く使う intermediate activation は保存しない。その結果、selective SSM layer の activation memory は optimized Transformer + FlashAttention と同程度になる。

attention layer はおよそ 12 bytes/token、MLP layer は約 20 bytes/token、合計約 32 bytes/token を保存する。一方 selective SSM 1 layer は約 16 bytes/token であるため、2 層の selective SSM が attention + MLP 1 組とほぼ同じ activation memory になる。

## E.5 Efficiency Benchmark

### Scan Operation

A100 80GB PCIe GPU 上で selective SSM の parallel scan を convolution / attention と比較する。ここで測るのは core operation のみであり、convolution kernel construction や attention の QKV projection は含めない。

baseline の PyTorch parallel scan は kernel fusion を使わず $\overline{\mathbf{A}},\overline{\mathbf{B}},\mathbf{C}$ を HBM に materialize する。提案実装は discretization と parallel scan を fuse し、大きな intermediate parameter の HBM materialization を避ける。

convolution は PyTorch の標準 FFT 実装を使い、理論計算量は $O(L\log L)$。attention は causal FlashAttention-2 と比較する。batch size 1、$D=1024$、$N=16$、BF16 で sequence length を 512 から約 500K まで増やす。

### End-to-end Inference

Mamba 1.4B と未学習 Mamba 6.9B を、GPT-3 architecture の Transformer 1.3B / 6.7B と比較する。prompt length 2048、generation length 128、batch size 1〜128 とし、128 token を生成する時間から throughput を求める。3 回測定の平均を報告し、A100 80GB PCIe GPU を用いる。
