# Transformers are SSMs: Structured State Space Duality による一般化モデルと効率的アルゴリズム

Tri Dao, Albert Gu

## 概要

Transformer は言語モデリングにおける深層学習の成功を支える主要なアーキテクチャである一方、Mamba などの State Space Model（SSM）は近年、小規模から中規模の設定において Transformer と同等、あるいはそれを上回る性能を示している。本論文では、これら2つのモデル族が実際には密接に関係していることを示し、よく研究されている構造化半分離可能行列（structured semiseparable matrices）のさまざまな分解を介して、SSM と attention の変種を結び付ける理論的枠組みを構築する。

著者らが **State Space Duality（SSD）** と呼ぶこの枠組みにより、新しいアーキテクチャ **Mamba-2** を設計する。Mamba-2 の中心層は Mamba の selective SSM を洗練したものであり、言語モデリングにおいて Transformer と競合する性能を維持しながら、Mamba の selective SSM より 2〜8 倍高速に計算できる。

---

# 1. はじめに

Transformer、特に GPT や Llama のような decoder-only モデルは、入力系列を causal に処理することで、現代の深層学習を大きく発展させてきた。しかし attention は、学習時には系列長に対して二乗の計算量を必要とし、自己回帰生成時には系列長に比例する KV cache を保持する必要がある。

一方で、Structured State Space Model（SSM）は、学習時の計算量が系列長に対して線形であり、生成時には一定サイズの状態だけを保持すればよい代替系列モデルとして発展してきた。S4 は長距離依存タスクで強い性能を示し、Mamba は小〜中規模の言語モデリングで Transformer と同等以上の性能を示している。

しかし、SSM の発展は Transformer の理論・アルゴリズム・ハードウェア最適化の研究とは比較的独立に進んできた。そのため、Transformer で蓄積された最適化手法を SSM にそのまま移植することは難しく、SSM は理論的にも実装上も Transformer より扱いにくい面が残っている。

本論文の主目的は、**構造化 SSM と attention の変種の間に豊富な理論的接続を与えること**である。この接続を利用し、Transformer 用に発展したアルゴリズムやシステム最適化を SSM に移植し、系列長に対するスケーリングを改善しながら Transformer を上回る foundation model の構築を目指す。

Linear Attention は、この方向の先駆的研究である。autoregressive attention と線形 RNN の間に「dual form」が存在し、二乗計算量の kernelized attention と特定の線形 recurrence が等価であることを示した。本論文はこの考えを一般化し、SSM に対しても **線形時間の recurrent form** と **二乗時間の attention-like form** を同時に持つモデル族を導く。

## State Space Duality

本論文では、構造化 SSM と attention の変種を結ぶ枠組みを **Structured State Space Duality（SSD）** と呼ぶ。中心となる抽象化は **structured matrix** であり、これは二乗未満のパラメータ数で表現でき、行列積も二乗未満で計算できる行列を指す。

主な理論的貢献は以下である。

1. SSM と **semiseparable matrix（半分離可能行列）** が等価であることを示す。
2. Linear Attention を tensor contraction の観点から導出し、それを **Structured Masked Attention（SMA）** に一般化する。
3. SSM と SMA の大きな共通部分を明らかにし、その部分では SSM 型の線形形式と attention 型の二乗形式が完全に双対となることを示す。
4. 高速な recurrent form を持つ kernel attention は必ず SSM として表現できることを示す。

## 効率的アルゴリズム

SSD により、SSM を structured matrix multiplication として捉え直すことができる。本論文では semiseparable matrix をブロック分解し、対角ブロックを attention 型の二乗形式で、非対角ブロックを低ランク分解と recurrence で処理する。

この SSD アルゴリズムは、

- 系列長に対して線形の計算量
- matrix multiplication unit を利用可能
- Mamba の selective scan より 2〜8 倍高速
- Mamba より大きな state size を小さな速度低下で使用可能
- FlashAttention-2 と比較して系列長約 2K 以上で高速、16K では約6倍高速

という特徴を持つ。

## Mamba-2

SSD の観点から Mamba を再設計したものが Mamba-2 である。主な変更は、SSM パラメータの projection を並列化すること、追加の normalization を入れること、multi-head attention の考え方を SSM に移植すること、そして tensor parallelism に適した構造にすることである。

# 2. 背景と概要

## 2.1 Structured State Space Models

Structured State Space Model（S4）は、RNN、CNN、古典的な state space model と関連する系列モデルである。1次元系列 $x \in \mathbb{R}^T$ を $y \in \mathbb{R}^T$ に写像し、内部に潜在状態 $h \in \mathbb{R}^{T \times N}$ を持つ。

一般的な離散時間 SSM は、

$$
h_t = A h_{t-1} + Bx_t,
\tag{1a}
$$

$$
y_t = C^\top h_t,
\tag{1b}
$$

と書ける。ここで

$$
A \in \mathbb{R}^{N\times N},\qquad
B,C \in \mathbb{R}^{N\times 1}.
$$

Mamba で導入された selective SSM ではパラメータを時刻ごとに変化させ、

$$
h_t = A_t h_{t-1} + B_t x_t,
\tag{2a}
$$

$$
y_t = C_t^\top h_t
\tag{2b}
$$

とする。

SSM が「structured」と呼ばれるのは、時間発展を支配する $A$ が、深層ニューラルネットワークで効率的に計算できるよう特別な構造を持つ必要があるためである。従来は diagonal plus low-rank（DPLR）や diagonal などの構造が利用されてきた。

### 連続時間モデルとしての SSM

初期の structured SSM は離散系列ではなく連続時間信号 $x(t) \mapsto y(t)$ として定義されていた。連続パラメータと step size $\Delta$ を discretization rule によって離散パラメータ $(A,B)$ に変換する。本論文では議論を簡潔にするため、以降はこの離散化の詳細を省略し、離散パラメータを直接扱う。

### RNN としての SSM

式 (1)、(2) は入力に対して線形な recurrence であり、SSM は RNN の一種として解釈できる。通常の RNN と異なり線形性を持つため、逐次計算を避ける並列アルゴリズムを構成できる。

### CNN としての SSM

$A,B,C$ が時間に依存しない Linear Time-Invariant（LTI）SSM は convolution と等価である。このため従来の SSM は、学習時には convolution mode、自己回帰推論時には recurrent mode を使い分けることができた。

### Selective SSM

Mamba の selective SSM では $(A_t,B_t,C_t)$ が入力に依存して変化する。そのため各時刻の入力を選択的に記憶または無視でき、言語のような情報密度の高いデータで LTI SSM より強い性能を示す。

一方で、時間変化するため convolution mode を使用できず、効率化には hardware-aware な scan 実装が必要になる。また通常の行列積を中心に実装される Transformer と比較すると、GPU/TPU の matrix multiplication unit を十分に活用しにくい。

### Sequence transformation としての SSM

**定義 2.1** 系列変換を、

$$
Y=f_\theta(X),
$$

という写像と呼ぶ。ここで $X,Y\in\mathbb{R}^{T\times P}$ であり、$T$ は sequence/time 軸、$P$ は特徴次元である。

式 (2) の SSM は $P=1$ の系列変換である。$P>1$ の場合には独立した $P$ 本の系列に同じ SSM を broadcast して適用できる。

**定義 2.2** SSM operator を

$$
\operatorname{SSM}(A,B,C):X\mapsto Y
$$

とし、式 (2) によって定義される系列変換とする。

状態次元 $N$ は自由なハイパーパラメータであり、**state size / state dimension / state expansion factor** と呼ぶ。

**定義 2.3** 系列変換が

$$
Y=M_\theta X
$$

と書けるとき、これを matrix transformation と呼ぶ。

## 2.2 Attention

一般的な self-attention は

$$
Y=\operatorname{softmax}(QK^\top)V
$$

で定義される。$QK^\top$ によりすべての位置対の相互作用を明示的に構成するため、学習時の計算量は系列長に対して二乗となる。

Linear Attention では softmax を kernel feature map に置き換え、行列積の結合則

$$
(QK^\top)V=Q(K^\top V)
$$

を利用する。causal mask $L$ を用いる場合、

$$
(L\circ QK^\top)V
$$

を recurrence として展開できる。

本論文ではこの考えをさらに一般化し、$L$ を任意の structured matrix に拡張した Structured Masked Attention を導入する。

## 2.3 Structured Matrices

一般の $T\times T$ 行列は $T^2$ 個のパラメータを必要とし、行列積も $O(T^2)$ の計算を必要とする。

structured matrix とは、

1. 二乗未満、理想的には線形個のパラメータで圧縮表現でき、
2. その圧縮表現を利用して行列積などを高速に計算できる

行列である。

代表例には sparse、low-rank、Toeplitz、Cauchy、Vandermonde、butterfly matrix などがある。本論文では、SSM が **semiseparable matrix** と等価であることを示す。

## 2.4 Structured State Space Duality の概要

SSD では sequence model を2つの観点から扱う。

- **matrix transformation**：系列方向に作用する行列として見る。
- **tensor contraction**：複数テンソルの縮約順序として見る。

SSM 側では semiseparable matrix が中心的な構造となり、attention 側では structured mask を持つ attention が中心となる。両者の共通部分が SSD である。

## 2.5 記法

系列長を $T$、source length を $S$、state / feature dimension を $N$、head dimension を $P$ とする。

積の省略記法として、たとえば

$$
A_{j:i}^{\times}=A_jA_{j-1}\cdots A_{i+1}
$$

を用いる。スカラー系列についても同様に

$$
a_{j:i}^{\times}=a_j a_{j-1}\cdots a_{i+1}
$$

と書く。

# 3. State Space Model は Structured Matrix である

本節では SSM を系列変換として異なる観点から捉え、SSM と semiseparable matrix の等価性を示す。

## 3.1 SSM の Matrix Transformation Form

式 (2) を展開すると、初期状態を0として

$$
h_0=B_0x_0,
$$

$$
h_t
=
A_t\cdots A_1B_0x_0
+A_t\cdots A_2B_1x_1
+\cdots
+A_tB_{t-1}x_{t-1}
+B_tx_t.
$$

したがって

$$
h_t=
\sum_{s=0}^{t}A_{t:s}^{\times}B_sx_s.
$$

$C_t^\top$ を左から掛けると、

$$
y_t=
\sum_{s=0}^{t}C_t^\top A_{t:s}^{\times}B_sx_s.
$$

これを系列全体で行列化すると、

$$
y=\operatorname{SSM}(A,B,C)(x)=Mx,
\tag{3}
$$

$$
M_{ji}=C_j^\top A_{j:i}^{\times}B_i
\qquad (j\ge i),
$$

となる。$M$ は causal な下三角行列である。

## 3.2 Semiseparable Matrices

**定義 3.1** 下三角行列 $M$ の対角線以下に完全に含まれる任意の部分行列の rank が高々 $N$ であるとき、$M$ を **$N$-semiseparable** と呼ぶ。$N$ を semiseparable order/rank と呼ぶ。

### 3.2.1 Sequentially Semiseparable（SSS）表現

**定義 3.2** 下三角行列 $M\in\mathbb{R}^{T\times T}$ が

$$
M_{ji}=C_j^\top A_j\cdots A_{i+1}B_i
\tag{4}
$$

と書けるとき、$M$ は $N$-sequentially semiseparable（SSS）表現を持つという。

ここで

$$
B_i,C_j\in\mathbb{R}^N,
\qquad
A_t\in\mathbb{R}^{N\times N}.
$$

この演算子を

$$
M=\operatorname{SSS}(A,B,C)
$$

と書く。

**補題 3.3** $N$-SSS 表現を持つ行列は $N$-semiseparable である。

非対角ブロックを取ると、そのブロックは $N$ 次元の中間状態を介して left factor と right factor に分解できるため rank は高々 $N$ になる。

**命題 3.4** 逆に、任意の $N$-semiseparable matrix は $N$-SSS 表現を持つ。

したがって semiseparable matrix と SSS 表現は本質的に等価である。

### 3.2.2 1-Semiseparable Matrix と scalar SSM recurrence

$N=1$ の場合、$B_i,C_j,A_t$ はスカラーになる。$b,c$ は対角行列として外に出せるので、核となる構造は

$$
M_{ji}=a_{j:i}^{\times}
$$

である。

これを

$$
M=\operatorname{1SS}(a_{0:T})
\tag{6}
$$

と書く。具体的には

$$
\operatorname{1SS}(a)=
\begin{bmatrix}
1 & 0 & 0 & \cdots \\
a_1 & 1 & 0 & \cdots \\
a_2a_1 & a_2 & 1 & \cdots \\
\vdots & \vdots & \ddots & \ddots
\end{bmatrix}.
$$

$y=Mx$ は

$$
y_t=a_t y_{t-1}+x_t
$$

という最小の scalar recurrence と等価である。この1-SS 行列積は後の SSD アルゴリズムでも重要になる。

## 3.3 SSM は Semiseparable Matrix である

式 (3) と式 (4) を比較すると、SSM の matrix transformation はそのまま SSS representation である。

**定理 3.5** 状態次元 $N$ の SSM は $N$-semiseparable matrix transformation と等価である。

すなわち

$$
\operatorname{SSM}(A,B,C)(x)
=
\operatorname{SSS}(A,B,C)x.
$$

この結果により、「SSM を計算する」という問題は「semiseparable matrix を入力系列に掛ける」という structured matrix multiplication の問題に置き換えられる。

## 3.4 Structured Matrix Algorithm としての SSM 計算

SSM の異なる計算方法は、semiseparable matrix multiplication の異なるアルゴリズムと解釈できる。

### 3.4.1 線形時間の recurrent mode

通常の recurrence

$$
h_t=A_th_{t-1}+B_tx_t,
$$

$$
y_t=C_t^\top h_t
$$

を順に計算すれば、系列長 $T$ に対して線形時間で計算できる。

特に $A_t$ が diagonal の場合、各 state channel の recurrence は独立であり、scalar scan の集合として実装できる。

### 3.4.2 二乗時間の naive mode

一方、式 (3) の $M$ を明示的に構築して

$$
y=Mx
$$

とすれば二乗時間で計算できる。通常は非効率であるが、行列積 unit を利用しやすいという利点があり、後の attention との双対性を明確にする。

### 3.4.3 まとめ

SSM は同じ数学的写像に対して、

- recurrent / linear form
- matrix / quadratic form

という2つの計算形式を持つ。

# 4. Structured Masked Attention：Linear Attention の Structured Matrix による一般化

本節では Linear Attention を tensor contraction から導出し、それを Structured Masked Attention（SMA）へ一般化する。

## 4.1 Attention の枠組み

### 4.1.1 Attention

single-head attention は3つの系列 $(Q,K,V)$ から $Y$ を生成する写像である。

$$
Q\in\mathbb{R}^{T\times N},\qquad
K\in\mathbb{R}^{S\times N},\qquad
V\in\mathbb{R}^{S\times P}.
$$

基本形は

$$
G=QK^\top\in\mathbb{R}^{T\times S},
$$

$$
M=f(G),
$$

$$
Y=MV\in\mathbb{R}^{T\times P}.
\tag{9}
$$

softmax attention では $f=\operatorname{softmax}$ とする。

### 4.1.2 Self-Attention

self-attention では通常、

- $S=T$
- $N=P$
- $Q=W_QX$, $K=W_KX$, $V=W_VX$

とする。

本論文では attention の双対性を議論しやすくするため、$Q,K,V$ をすでに生成済みのテンソルとして扱う。

### 4.1.3 Kernel Attention

softmax の指数部分は kernel feature map $\phi$ を使って

$$
\exp(QK^\top)=\phi(Q)\phi(K)^\top
$$

と考えられる。feature map を $Q,K$ の定義に吸収すれば、kernel attention の核は単に $QK^\top V$ として扱える。

既存の kernel attention には Linear Attention、Random Feature Attention、Performer、cosFormer などが含まれる。

### 4.1.4 Masked Kernel Attention

mask $L\in\mathbb{R}^{T\times S}$ を使う masked attention は

$$
Y=(L\circ(QK^\top))V
\tag{10}
$$

と書ける。$\circ$ は要素積である。

計算を分解すると、

$$
G=QK^\top,
$$

$$
M=G\circ L,
$$

$$
Y=MV.
\tag{11}
$$

これを1つの tensor contraction とみなすと、

$$
Y=
\operatorname{contract}(TN,SN,SP,TS\to TP)(Q,K,V,L).
\tag{12}
$$

通常の二乗時間 attention は次の縮約順序である。

$$
G=
\operatorname{contract}(TN,SN\to TS)(Q,K),
\tag{13a}
$$

$$
M=
\operatorname{contract}(TS,TS\to TS)(G,L),
\tag{13b}
$$

$$
Y=
\operatorname{contract}(TS,SP\to TP)(M,V).
\tag{13c}
$$

## 4.2 Linear Attention

causal mask が下三角の1行列である場合、Linear Attention は概念的には

$$
Y=Q\cdot\operatorname{cumsum}(K^\top V)
\tag{14}
$$

として計算できる。

**命題 4.1** autoregressive kernel attention は、各時刻あたり定数時間の recurrence により、系列長 $T$ に対して線形時間で計算できる。

### 4.2.1 Tensor Contraction による証明

式 (12) の縮約順序を変える。

$$
Z=
\operatorname{contract}(SP,SN\to SPN)(V,K),
\tag{15a}
$$

$$
H=
\operatorname{contract}(TS,SPN\to TPN)(L,Z),
\tag{15b}
$$

$$
Y=
\operatorname{contract}(TN,TPN\to TP)(Q,H).
\tag{15c}
$$

causal mask $L$ が lower-triangular ones のとき、式 (15b) は source 軸の累積和に等しい。したがって二乗サイズの attention matrix を明示的に構築せずに済む。

Linear Attention の本質は、単なる「行列積の結合則」ではなく、**4-way tensor contraction の縮約順序を変更し、mask $L$ に対する高速な structured multiplication を利用すること**である。

## 4.3 Structured Masked Attention

以上から、Linear Attention は causal mask に限定する必要がない。$L$ が高速な行列積を持つ structured matrix であれば、式 (15b) を高速に計算できる。

**定義 4.2** Structured Masked Attention（SMA）とは、

$$
Y=(L\circ(QK^\top))V
$$

において $L$ を structured matrix とした attention である。

これにより、mask 自体に再帰構造、減衰、入力依存性などを持たせられる。

### 4.3.1 Masked Attention の dual form

SMA は同じ演算を次の2形式で計算できる。

**Quadratic form**

$$
G=QK^\top,
\qquad
M=L\circ G,
\qquad
Y=MV.
$$

**Linear / structured form**

$$
Z=VK,
\qquad
H=LZ,
\qquad
Y=QH,
$$

ただし実際にはそれぞれ適切な tensor contraction として解釈する。計算量は $L$ の structured matrix multiplication の効率に依存する。

# 5. State Space Duality

Sections 3 と 4 では、それぞれ SSM と structured attention が線形形式と二乗形式を持つことを示した。本節では両者を直接結び付ける。

## 5.1 Scalar-Identity Structured SSM

一般の SSM matrix は

$$
M_{ji}=C_j^\top A_{j:i}^{\times}B_i
$$

である。

ここで

$$
A_t=a_t I
$$

とし、状態遷移が scalar × identity という強い構造を持つ場合を考える。このとき

$$
M_{ji}=a_{j:i}^{\times}(C_j^\top B_i).
$$

$L=\operatorname{1SS}(a)$ と置くと、系列全体では

$$
M=L\circ(CB^\top).
$$

したがって

$$
Y=MX
$$

は

$$
G=
\operatorname{contract}(TN,SN\to TS)(C,B),
$$

$$
M=
\operatorname{contract}(TS,TS\to TS)(G,L),
$$

$$
Y=
\operatorname{contract}(TS,SP\to TP)(M,X)
\tag{16}
$$

と計算できる。

これは Section 4 の masked kernel attention と完全に同じ形である。すなわち scalar-identity SSM の naive quadratic form は、1-semiseparable mask を持つ kernel attention そのものである。

## 5.2 1-Semiseparable Structured Masked Attention

通常の causal mask は

$$
L=\operatorname{1SS}(\mathbf{1})
$$

である。つまり Linear Attention は、すべての decay が $a_t=1$ である特殊な 1-SS mask と解釈できる。

これを任意の $a_t$ に一般化したものが **1-semiseparable SMA（1-SS SMA）** である。Linear Attention の cumsum を scalar SSM scan に置き換えたものと考えられる。

**系 5.1** 1-SS SMA は、$A_t=a_tI$ を持つ diagonal SSM の特殊例である。

さらに、

**定理 5.2** bounded order の autoregressive process として実装できる Structured Masked Attention では、その structured mask $L$ は semiseparable matrix でなければならない。

したがって **効率的な autoregressive attention は semiseparable SMA によって特徴付けられる**。

1-SS SMA は、

- input-dependent recurrence を持つ Linear Attention の自然な一般化
- efficient autoregressive attention である semiseparable SMA の最小例
- diagonal SSM の特殊例

という3つの意味で重要である。

## 5.3 Structured State-Space Duality（SSD）

結果をまとめると、

- SSM は通常、線形時間 recurrence として定義されるが、matrix form を展開すると二乗時間形式を持つ。
- Attention は通常、二乗時間 pairwise interaction として定義されるが、tensor contraction の順序を変えると線形形式を持つ。
- $A_t=a_tI$ の SSM と 1-semiseparable mask を持つ SMA は、**同じ線形形式と二乗形式を持つ完全な dual** である。

この共通部分を **Structured State Space Duality（SSD）** と呼ぶ。

# 6. SSD モデルの Hardware-Efficient Algorithm

SSD の理論的接続を利用して、SSM の計算を matrix multiplication unit に適した形に変換する。

**定理 6.1** state expansion factor $N$、head dimension $P=N$ の SSD モデルは、入力 $X\in\mathbb{R}^{T\times P}$ に対して、

- 学習 FLOPs: $O(TN^2)$
- 推論 FLOPs: $O(N^2)$ / token、系列全体では $O(TN^2)$ 相当
- 推論状態 memory: $O(N^2)$
- 主な処理を matrix multiplication で構成

するアルゴリズムを持つ。

## ブロック分解の基本アイデア

semiseparable matrix $M$ を block size $Q$ で分割する。

$$
M=
\begin{bmatrix}
M^{(0,0)} & & & \\
M^{(1,0)} & M^{(1,1)} & & \\
\vdots & \vdots & \ddots & \\
M^{(K-1,0)} & M^{(K-1,1)} & \cdots & M^{(K-1,K-1)}
\end{bmatrix},
$$

ここで $K=T/Q$ である。

semiseparable matrix の定義より、

- **対角ブロック**：chunk 内の完全な SSM 計算
- **非対角ブロック**：rank $N$ 以下の low-rank factorization

を持つ。

対角ブロックは attention 型の quadratic form を使い matrix multiplication で計算する。非対角ブロックは、SSM の state を介した low-rank factorization を利用する。

## 6.1 Diagonal Blocks

各 chunk の内部では長さが $Q$ に制限されるため、二乗形式を使ってもコストは抑えられる。

各 chunk について

$$
M^{(j,j)}
=
\operatorname{SSM}
(A_{jQ:(j+1)Q},B_{jQ:(j+1)Q},C_{jQ:(j+1)Q})
$$

を構成し、SMA の quadratic form で計算する。

これにより、GPU の高速な matmul を利用できる。

## 6.2 Low-Rank Blocks

非対角 block は3段階に分けて計算できる。

### Right factors：input → state

各 chunk 内の入力から、その chunk の初期状態を0と仮定したときの最終状態を求める。

計算は chunk ごとに $(N,Q)\times(Q,P)$ の行列積となる。

### Center factors：state → state

各 chunk から得た終端 state を、chunk 間の recurrence で伝播する。

系列長は元の $T$ ではなく $T/Q$ になっているため、scalar SSM scan のコストは大幅に小さい。

### Left factors：state → output

前 chunk までの情報を含む初期状態から、現在 chunk の各出力への寄与を計算する。chunk ごとに

$$
\operatorname{contract}(QN,NP\to QP)
$$

の行列積となる。

最終出力は

$$
Y=Y_{\mathrm{diag}}+Y_{\mathrm{off}}
$$

として、chunk 内計算と chunk 間計算を加算する。

## 6.3 計算量

Batched Matrix Multiplication を

$$
\operatorname{BMM}(B,M,N,K)
$$

とし、batch $B$ 個の $(M\times K)(K\times N)$ 行列積を表す。

block size を

$$
Q=N=P
$$

とすると、主要な行列積はすべておおむね

$$
\operatorname{BMM}(T/N,N,N,N)
$$

の形になる。

したがって、

- FLOPs: $O(TN^2)$
- memory: $O(TN)$
- 主要演算: $N\times N$ の matrix multiplication

となる。

比較すると以下のようになる。

| 項目 | Attention | SSM | SSD |
|---|---:|---:|---:|
| State size | $T$ | $N$ | $N$ |
| Training FLOPs | $T^2N$ | $TN^2$ | $TN^2$ |
| Inference FLOPs | $TN$ | $N^2$ | $N^2$ |
| Naive memory | $T^2$ | $TN^2$ | $TN$ |
| Matrix multiplication を主に利用 | ✓ |  | ✓ |

通常の attention は matmul に非常に適しているが $T^2N$ の計算を必要とする。純粋な SSM は $TN^2$ だが scan が主となり matmul unit を十分に使えない。SSD は両者の長所を組み合わせる。

### SSD の PyTorch 実装の流れ

論文 Listing 1 の実装は概念的に次の5段階からなる。

1. 系列を長さ `block_len` の chunk に並べ替える。
2. chunk 内の対角 block を SMA の二乗形式で計算する。
3. 各 chunk の入力から終端 state を計算する。
4. chunk 間で scalar SSM recurrence を適用する。
5. chunk 開始 state から各出力への寄与を計算し、chunk 内出力と加算する。

この実装は general selective scan より単純で、専用 low-level kernel がなくても PyTorch で比較的効率よく実装できる。

# 7. Mamba-2 Architecture

SSD により SSM と attention の共通語彙が得られる。本節では Transformer 由来の設計原理を SSD layer に移し、Mamba-2 を構成する。

## 7.1 Block Design

### Parallel Parameter Projections

Mamba-1 では selective SSM を

$$
X\mapsto Y
$$

という写像として捉え、$A,B,C$ を SSM 入力 $X$ の関数として生成していた。そのため、まず $X$ を projection し、その後に $A,B,C$ を逐次的に生成する構造になっていた。

Mamba-2 では SSD layer を

$$
(A,X,B,C)\mapsto Y
$$

という写像として捉える。この観点では $A,X,B,C$ を block 冒頭の単一 projection から並列に生成する方が自然である。

これは attention において $Q,K,V$ を並列 projection で生成する構造に対応する。

この変更はパラメータをわずかに削減し、Megatron 型の tensor parallelism に適した構造になる。

### Extra Normalization

大規模モデルでは学習不安定性が起きやすいため、最終 output projection の直前に LayerNorm、GroupNorm、RMSNorm などの normalization を追加する。

これは NormFormer に類似した変更であり、実験では性能と学習安定性の双方を改善する。

## 7.2 Sequence Transformation の Multihead Pattern

SSM は

- state parameter $A,B,C$ に state dimension $N$
- input $X$ に head dimension $P$
- sequence transformation に head 数 $H$

を持つと考えられる。

モデル次元を $D$ とすると、通常

$$
D=HP
$$

とする。Mamba-2 では Transformer と同様、$N,P$ を64または128程度に固定し、モデルサイズ増大時には head 数 $H$ を増やす。

### Multi-head SSM（MHS） / Multi-head Attention（MHA）

各 head が独立した $A,B,C,X$ を持つ。

$$
X:(T,H,P),\quad
A:(T,H),\quad
B:(T,H,N),\quad
C:(T,H,N).
\tag{17}
$$

### Multi-contract SSM（MCS） / Multi-query Attention（MQA）

$X$ と $B$ を head 間で共有し、$C$ のみ head ごとに独立とする。

$$
X:(T,1,P),\quad
A:(T,H),\quad
B:(T,1,N),\quad
C:(T,H,N).
\tag{18}
$$

### Multi-expand SSM（MES） / Multi-key Attention（MKA）

$B$ を head ごとに独立とし、$C,X$ を共有する。

$$
X:(T,1,P),\quad
A:(T,H),\quad
B:(T,H,N),\quad
C:(T,1,N).
\tag{19}
$$

### Multi-input SSM（MIS） / Multi-value Attention（MVA）

$X$ を head ごとに独立とし、$B,C$ を共有する。

$$
X:(T,H,P),\quad
A:(T,H),\quad
B:(T,1,N),\quad
C:(T,1,N).
\tag{20}
$$

**命題 7.2** Mamba-1 の selective SSM（S6）layer は、

- head dimension $P=1$
- $A$ は channel ごとに独立
- $B,C$ はすべての input channel で共有

であるため、**MIS / MVA head pattern** と解釈できる。

この attention との対応関係により、SSM の head sharing pattern を体系的に比較できる。

## 7.3 Linear Attention から導かれるその他の SSD 拡張

SSD は kernel attention と同じ二乗形式を持つため、Linear Attention で提案されてきたさまざまな kernel feature map を組み込むことができる。

例として、

- pointwise activation による kernel
- Random Feature Attention
- Performer の positive random feature
- cosFormer
- Based / ReBased の高次 feature expansion

などが挙げられる。

また softmax attention の denominator に相当する normalization を加えることも可能である。ただし実験では、多くの variant でこの normalization は不安定性を引き起こした。

---

# 8. SSM の Systems Optimization

Mamba-2 の block design は、大規模 Transformer で確立された分散学習手法を SSM に適用しやすくする。

## 8.1 Tensor Parallelism

Mamba-1 では $X$ を生成した後に $A,B,C$ を逐次生成するため、tensor parallelism を行うと複数回の通信同期が必要になる。

Mamba-2 では $A,B,C,X$ を最初にまとめて projection するため、Transformer の $Q,K,V$ projection と同様の sharding pattern を利用でき、通信回数を削減できる。

また output projection も標準的な row-parallel 形式にできる。

## 8.2 Sequence Parallelism

sequence dimension を複数 device に分割し、各 device が chunk を担当する sequence parallelism も SSD に適用できる。

SSD の block decomposition では chunk 境界に渡す state のみを通信すればよいため、系列全体を device 間で頻繁に同期する必要はない。

## 8.3 Variable Length

LLM 学習では複数文書を1つの長い sequence に packing することが多い。attention では文書境界を跨がないよう mask を設定する。

SSM でも文書境界で state を reset する必要がある。SSD の semiseparable mask 表現では境界位置の decay を適切に設定することで、padding を大量に導入せず variable-length sequence を扱える。

# 9. 実験的検証

## 9.1 Synthetic Task：Associative Recall

Mamba-2 の state capacity を検証するため、Multi-Query Associative Recall（MQAR）を使用する。

Mamba-1 はこの難しい設定で苦戦するが、Mamba-2 は広い条件で高い性能を示す。state size を制御して $N=16$ としても Mamba-2 は Mamba-1 より大幅に良い。

また、

$$
N=16\rightarrow64\rightarrow256
$$

と state size を大きくすると性能が一貫して向上する。これはより大きな state がより多くの key-value pair を記憶できることを示唆する。

## 9.2 Language Modeling

Mamba-2 を標準的な autoregressive language modeling で評価する。モデルサイズは GPT-3 の仕様に合わせて約125Mから2.7Bまでとし、Pile dataset を用いる。

## 9.3 Speed Benchmark

SSD を Mamba selective scan および FlashAttention-2 と比較する。

SSD は計算を matrix multiplication に再定式化して tensor core を活用できるため、Mamba の fused associative scan より **2〜8倍高速**である。

また系列長に対して線形にスケールするため、sequence length 約2K以上では FlashAttention-2 より高速となる。state expansion を大きくした場合にも Mamba scan ほど速度が悪化せず、大きな state size を扱える。

ただし短い系列では、Mamba-2 モデル全体が Transformer より必ずしも高速とは限らない。同一 parameter 数で Transformer は MLP と attention を半々程度持つ一方、pure Mamba-2 は全 layer が SSD である。MLP は非常に hardware-efficient であるため、短系列では SSD + MLP の hybrid 化が有効な場合がある。

# 10. 関連研究と議論

## 10.1 State Space Models

Structured SSM は、線形 recurrence、continuous-time system、global convolution の間を結ぶモデルとして発展してきた。S4 以降、$A$ の diagonal / DPLR 構造、state initialization、discretization、selectivity などが研究されている。

Mamba の selective SSM は $A,B,C$ を入力依存にし、言語のような情報密度の高い系列で大きく性能を改善した。本論文の SSD は、Mamba の selective SSM のうち scalar-identity $A$ を用いる重要な部分を attention と直接結び付ける。

一般の SSM は SSD より広い。SSD では $A_t=a_tI$ という制約がある一方、一般 SSM は任意の structured $A_t$ を持つ。しかし SSD の制約は hardware efficiency と attention duality を得るための重要な設計点である。

## 10.2 Structured Matrices

semiseparable matrix は数値線形代数で長く研究されてきた structured matrix の一種であり、SSS、HSS、Bruhat など複数の表現を持つ。

本論文は semiseparable matrix を deep sequence model の中心的な表現として利用し、SSM recurrence、attention、structured matrix multiplication を同一枠組みに置く。

## 10.3 Linear Attention

Linear Attention は causal kernel attention を recurrence に変換する枠組みを与えた。RetNet、GateLoop、TransNormer などは decay や gate を導入してこの構造を一般化している。

本論文の Structured Masked Attention は、これらを structured mask $L$ の選択として統一的に表現する。また efficient autoregressive attention の mask が semiseparable でなければならないことを示し、Linear Attention と SSM の関係をより一般的な理論へ拡張する。

## 10.4 Related Models

Mamba-2 と近い発想を持つモデルとして、RetNet、GateLoop、TransNormer、RWKV、linear attention 系モデルなどがある。これらの多くは recurrence、decay、gating、kernel attention のいずれかの観点から導出されているが、SSD ではそれらを structured matrix の観点から統一する。

---

# 11. 結論

本論文は、SSM と attention が互いに独立な系列モデルではなく、structured matrix を介して密接に結び付いていることを示した。

中心的な結果は、

1. SSM が semiseparable matrix と等価であること
2. Linear Attention を Structured Masked Attention に一般化できること
3. scalar-identity SSM と 1-semiseparable SMA が同一の linear / quadratic dual form を持つこと
4. この Structured State Space Duality を用いて hardware-efficient な SSD algorithm を構成できること
5. SSD を中心に Mamba を再設計した Mamba-2 が、高速かつ高性能な language model となること

である。

# 付録 B. Scalar SSM Scan（1-SS Multiplication）の効率的アルゴリズム

本付録では

$$
y=Mx,
\qquad
M=\operatorname{1SS}(a)
$$

を効率的に計算する複数の方法を整理する。

## B.1 問題定義

scalar SSM recurrence

$$
y_t=a_ty_{t-1}+x_t
$$

は 1-SS matrix multiplication と等価である。

この演算は scan / cumprodsum と考えることができ、SSM の基礎演算となる。

## B.2 古典的アルゴリズム

### B.2.1 Sequential Recurrence

最も単純には時刻順に recurrence を計算する。work は $O(T)$ だが depth も $O(T)$ であり、学習時の並列性が低い。

### B.2.2 Parallel Associative Scan

recurrence を結合的な二項演算に書き換え、parallel scan を適用できる。この場合、work は線形のまま depth を $O(\log T)$ にできる。

## B.3 Structured Matrix Decomposition に基づくアルゴリズム

1-SS matrix の自己相似性や low-rank structure を利用すると、scan 以外にも複数の計算方法を構成できる。

### B.3.1 Dilated Mode

行列を偶数・奇数などの dilated pattern に分割し、再帰的に問題サイズを縮小する。parallel scan と近い木構造の計算になる。

### B.3.2 State-Passing / Chunkwise Mode

系列を chunk に分け、各 chunk 内を独立に計算した後、chunk 間で state を受け渡す。本論文の SSD algorithm はこの考えを semiseparable matrix の block decomposition として一般化したものである。

### B.3.3 Fully Recurrent Mode

chunk size を1に近づけると通常の sequential recurrence に戻る。

### B.3.4 / B.3.5 Associative Scan Mode

分解方法を変えると標準的な associative scan に相当する形式も得られる。

これらはすべて同じ 1-SS matrix multiplication を異なる structured matrix decomposition により計算していると理解できる。

# 付録 C. 理論の詳細

## C.1 SSM の Closure Property

semiseparable matrix の観点から見ると、SSM には structured matrix としてさまざまな closure property がある。

たとえば適切な条件下で、SSM で表現される作用の和・積・composition も、state dimension を拡張した SSM として表せる。これは recurrence の状態を block 結合することに対応する。

この性質は、SSM が単なる特殊な recurrence ではなく、広い structured linear transformation class を形成していることを示す。

## C.2 Autoregressive Masked Attention は Semiseparable-Structured Attention である

Section 5.2 の定理 5.2 の証明を与える。

bounded-order autoregressive process は、有限次元の内部 state だけを過去から未来へ伝播する。したがって過去の入力群から未来の出力群への作用は、その内部 state 次元以下の rank に因数分解される。

この性質を sequence transformation matrix の任意の lower-triangular submatrix に適用すると、その rank が一様に有界となる。よって mask / transformation matrix は semiseparable でなければならない。

この結果により、semiseparable structure は単なる1つの効率化手法ではなく、**有限状態で効率的に autoregressive 計算できる attention の構造そのもの**として位置付けられる。

# 付録 D. 実験詳細

## D.1 MQAR

Associative Recall 実験では既存研究より難しい MQAR 設定を利用する。より長い系列、より小さいモデルを使用し、state size が key-value pair の記憶能力に与える影響を調べる。

比較対象には softmax multi-head attention、Based、Mamba-1 などを含む。

## D.2 Scaling Law

Pile dataset 上で約125M〜1.3B parameter のモデルを Chinchilla scaling の token 数で学習し、Mamba、Transformer++、Mamba-2 の validation perplexity と wall-clock efficiency を比較する。

## D.3 Downstream Evaluation

2.7B 規模では最大300B token まで学習し、LAMBADA、HellaSwag、PIQA、ARC-Easy、ARC-Challenge、WinoGrande、OpenBookQA などの zero-shot task で評価する。

## D.4 Ablation

block design、extra normalization、parallel projection、head sharing pattern、kernel approximation などを個別に変更し、Mamba-2 の性能差を検証する。
